# Overview

Orbit Lab is a small simulator for satellites in low Earth orbit. This handbook covers installing
it, running a first simulation, and the physics the simulator uses.

> [!NOTE]
> Every page of this handbook is a separate Markdown file. monodocs bundled them into this one PDF.
