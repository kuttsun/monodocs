# Getting Started

monodocs turns a directory of Markdown / AsciiDoc files into **one self-contained HTML file**. You keep your documentation split across many files; only the distributed artifact is bundled into a single file.

## What it produces

```bash
monodocs build ./docs -o ./dist/manual.html
```

The output is a single HTML with no external runtime: in-page search, a table of contents, prev/next navigation, dark mode, and a print layout are all embedded. Try the **Single-file sample** link in the top navigation — it is generated by monodocs from this project's own examples.

## Install

monodocs is published on npm and requires Node.js 22.12.0 or later. Linux x64 and Windows x64 are the supported platforms.

```bash
npm install -g monodocs
# Or run it without a global installation
npx monodocs build ./docs -o ./dist/manual.html
```

Add it to a project instead when you want the version pinned in the repository:

```bash
npm install -D monodocs
```

PDF output and Mermaid pre-rendering require a system-installed Chromium or Google Chrome; monodocs never downloads a browser. On Linux and Windows it is discovered automatically (Windows also falls back to Chromium-based Microsoft Edge). Set `PUPPETEER_EXECUTABLE_PATH` when the browser is installed in a non-standard location, or on platforms without built-in detection such as macOS.

## First build

```bash
# Single self-contained HTML
monodocs build ./docs -o ./dist/manual.html

# PDF (requires Chromium)
monodocs build ./docs --format pdf -o ./dist/manual.pdf

# Report broken links, missing images, and missing titles
monodocs validate ./docs
```

The input directory structure becomes the sidebar, and Markdown and AsciiDoc files may be mixed freely.

## Preview locally

```bash
# Live-reloading preview server on http://127.0.0.1:4173/
monodocs serve ./docs --open
```

## Run from source

To work on monodocs itself, build from the repository. The development toolchain runs **inside Docker**, so you don't need Node or pnpm on your host:

```bash
git clone https://github.com/kuttsun/monodocs.git
cd monodocs

scripts/app.sh pnpm install
scripts/app.sh pnpm build

# Build a single HTML from the bundled examples
scripts/app.sh node packages/cli/dist/index.js build examples/en -o dist/manual.html
```
