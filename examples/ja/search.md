# 検索

生成された単一 HTML には全文検索が組み込まれています。
辞書も検索ランタイムも同梱しないため、この機能のためにファイルが大きくなることはほとんどありません。

サイドバーの検索欄に語を入れると、タイトル、見出し、本文を対象に候補が絞り込まれます。
以下に挙げるクエリは、すべてこのサンプルに実在する語に当たります。
実際に入力しながら読んでください。

## 表記のゆれの扱い

日本語の文書では、同じ語でも書き手によって表記が揺れます。
入力した語と本文の表記が一字でも違えば当たらない、という状態にならないよう、次の違いは同じものとして扱います。

| 検索欄に入れる語 | 当たる本文 | 吸収している違い |
| --- | --- | --- |
| `はいらいと` | ハイライト | カタカナとひらがな |
| `ｲﾝｽﾄｰﾙ` | インストール | 半角カタカナと全角カタカナ |
| `コ―ド` | コード | 長音記号とダッシュ類 |
| `h2～h3` | h2〜h3 | 全角チルダと波ダッシュ |
| `ＰＤＦ` | PDF | 全角英数と半角英数 |

`コ―ド` の 2 文字目は長音記号ではなくダッシュです。
打ち間違えたまま入力しても、意図した語に当たります。

結果にはこのページ自身も出ます。
両方の表記をこの表に並べているためで、確かめたいのは他のページのほうです。
たとえば `はいらいと` で出てきたページを開くと、ひらがなで入力した語がカタカナの本文に印として付きます。

## 複数キーワードでの絞り込み

空白で区切ると、そのすべてを含むページだけが残ります。

まず `画像` と入力してください。
画像に触れているページが並びます。
続けて ` 埋め込み` を足すと、両方を含むページだけが残ります。

## 見出しに当たった結果

結果はタイトル、見出し、本文の順に重み付けされます。
見出しに当たった結果を開くと、ページの先頭ではなくその見出しまで移動します。

`インストール` と入力してください。
AsciiDoc サンプルの見出しに当たり、開くとその見出しの位置から表示されます。

## キーボード操作

検索欄から手を離さずに結果を辿れます。

- `↓` と `↑`：結果を移動します。両端で折り返します。
- `Enter`：選んでいる結果を開きます。まだ動かしていなければ先頭の結果を開きます。
- `Escape`：入力を消します。

検索欄の右端の × ボタンでも入力を消せます。
結果と本文の印も消え、カーソルは検索欄に残ります。

移動しているあいだもカーソルは検索欄に残るため、そのまま入力を続けて絞り込めます。
日本語入力の変換中はこれらのキーを IME に譲るので、変換候補の選択が妨げられることはありません。

## 本文のハイライト

結果を開くと、開いた先の本文でも一致した語に印が付きます。
印は検索を開いているあいだ残るので、前後ページへ移動しても、どこに語があるかを見失いません。
入力を書き換えるか消すと、本文は元の状態に戻ります。

## 緩く当てる語

表記のゆれのうち、送り仮名と英語の語形変化は、本文ではなく入力した語のほうを緩めて照合します。
辞書は使いません。

- **送り仮名**：漢字と漢字の間の仮名は、2 字まで、あってもなくても当たります。`埋込み` は `埋め込み` に当たります。
- **英語の語形変化**：語の頭からの語幹で当てます。`installing` は `install` としか書いていないページにも当たります。語幹が 4 字に満たない語は緩めません。

緩く当たったページは、そのまま一致したページより後ろに並びます。
本文の印は、入力した表記ではなく本文に書かれた表記に付きます。
