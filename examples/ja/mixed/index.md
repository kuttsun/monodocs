# Markdown / AsciiDoc 混在

同じフォルダ内に Markdown と AsciiDoc を混在させられます。形式をまたいだリンクも
単一 HTML 内の hash route に変換されます。

- このページ（Markdown）から [AsciiDoc の相棒ページ](companion.adoc) へ。
- 見出しを指すリンクは、その見出しの位置へ直接ジャンプします:
  [相棒ページの「アンカーの例」](companion.adoc#anchor-demo)。

## アンカー先の見出し

相棒ページから、この見出しを指すリンクが張られています。
