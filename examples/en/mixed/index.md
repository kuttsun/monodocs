# Markdown / AsciiDoc mixed

You can mix Markdown and AsciiDoc in the same folder. Cross-format links are also converted into
hash routes within the single HTML.

- From this page (Markdown) to [the AsciiDoc companion page](companion.adoc).
- A link that carries an anchor jumps straight to that heading:
  [“Anchor example” on the companion page](companion.adoc#anchor-demo).
