# Specification

This document is a sample of the difference monodocs writes between two versions. It was built from `examples/diff/en/earlier` as the earlier version and `examples/diff/en/current` as the new one, by running `monodocs build . --diff-from-dir ../earlier` in the new version's directory. The bar at the top switches between the two versions side by side and either version alone, and "Next change" walks the changes one by one. Each page in the sidebar shows one kind of change.

This document describes the device.

2. Wait for initialisation
3. Start operation
